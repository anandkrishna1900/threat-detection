# Security Policy

## Responsible Use

This platform is a **defensive security research and education project**.

### What this project is for

- Analyzing security events against data you own or have explicit written
  permission to analyze
- Research and experimentation using public datasets
- Learning detection engineering, SIEM concepts, and anomaly detection
- Portfolio demonstration in controlled, local environments

### What this project is NOT for

- Scanning, probing, or attacking systems you do not own or lack explicit
  written permission to test
- Processing real victim data, real credentials, or sensitive production logs
- Any activity that would violate laws in your jurisdiction

## Reporting a Security Vulnerability

If you discover a security vulnerability in this project, please:

1. **Do not open a public GitHub issue.**
2. Email the maintainer directly (add your contact address here).
3. Include: description of the vulnerability, steps to reproduce, and
   potential impact.
4. Allow reasonable time for a fix before public disclosure.

## Supported Versions

| Version | Supported |
|---------|-----------|

## Dataset Disclaimer

All datasets used in this project are publicly available research datasets
(CIC-IDS2017, UNSW-NB15, synthetic data). No real network traffic, user
data, or credentials are included in this repository.
