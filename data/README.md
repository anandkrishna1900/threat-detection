# Data Directory

This directory contains all datasets used by the platform.

## Structure

```
data/
├── raw/          ← Original, unmodified source files (never edited)
├── processed/    ← Normalized, cleaned versions ready for feature extraction
└── synthetic/    ← Programmatically generated datasets (Phase 17)
```

## Data Policy

**NEVER commit to this repository:**
- Real network capture files
- Logs containing personal or identifying information
- Credentials or authentication tokens
- Data from systems you do not own or have explicit permission to analyze

**Acceptable data:**
- Public benchmark datasets (CIC-IDS2017, UNSW-NB15, NSL-KDD)
- Synthetic data generated by `scripts/generate_synthetic_data.py`
- Anonymized sample fixtures for testing

## Caveats

See `docs/evaluation.md` (Phase 16) for known feature-leakage issues
and methodological caveats specific to each dataset.

Real-world production traffic differs significantly from any benchmark
dataset. Metrics reported on these datasets do not represent expected
generalization performance in production.
